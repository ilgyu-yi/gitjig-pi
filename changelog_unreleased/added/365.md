- `/freshness` measures installed-asset freshness on demand (SPEC §4.5, §5.9's measuring stage): it compares the committed pin, the verified installed-pin record and the clone's complete carried files through the pin's own carried aggregate, and renders one content-free line — `current`, `placement-mismatch` (run `node .github/bin/gitjig-bootstrap.mjs`), `session-stale` (run `/reload`) or `cannot-measure` — never provisioning, writing a pin or aborting. Known false positives: an intended local edit to a carried file reads placement-mismatch, a provision running at the same time reads placement-mismatch until it advances the record, and a case- or normalization-insensitive filesystem can read a rename. The launcher's provision run converges when every handed-over file is exactly the bytes the new pin lists (one only the old pin lists absent), under a present record each carried file both pins list is exactly the old or new bytes, one only the new pin lists is absent or new and one only the old pin lists is old or absent (under an absent record, every listed carried file is absent or new), a present record is a well-formed pin naming the same source with no path changing class, and every entry it reads can be read with no link on its path (the record excepted: read through a link, a dangling one as absent); otherwise it refuses or leaves the clone as it is, and a carried file neither pin lists is left alone. One step converges from every provision state the help names (the launcher's own refusals aside): make the handed-over files the new pin's bytes and remove old-only ones, make .pi/extensions and .gitjig real readable directories, remove the record, and under the carried roots keep only the listed files holding exactly their new bytes and the directories that hold them; `/freshness help` spells it out, and leaves provision's own further preconditions (SPEC §4.6) outside what it measures. It runs only when asked under a 2-second read budget and caches nothing; an always-on session surface waits for observed precision. (#365)
