- `npm run test:affected` runs only the tests a change is likely to break (changed tests, importers of changed modules, readers of changed paths, and real-Pi tests for extension-entry, prompt or skill changes), as the between-rounds local check; the whole suite remains the gate at the final head and in CI. Reviewer briefs now scope a reviewer's runs to the tests a finding is about, run a mutant survivor through the affected-test selection the change description names (else the finding's own tests), and report it as a candidate until the whole suite confirms it.
