- A `pr-size` reporting check now measures every pull request to the default branch or a `*-maintenance` line in this repository against SPEC §1.11's 2,400-line bound, by the platform's own per-file counts less the SPEC table-of-contents region and the membership snapshot. It names the measured value and the threshold, honours only an escape record at the current head of the same pull request from a writer that names the same value, and fails closed on an unmeasurable diff. It is not a required context, and it is source-only: no bound ships to adopters. (#408)
