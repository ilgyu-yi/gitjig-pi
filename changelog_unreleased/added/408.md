- A `pr-size` reporting check now measures every pull request to the default branch against SPEC §1.11's 2,400-line bound, by the platform's own per-file counts less the SPEC table-of-contents region and the membership snapshot. It names the measured value and the threshold, honours only an escape record at the current head of the same pull request from a writer that names the same value, and fails closed on an unmeasurable diff; it is not a required context, and an adopter's own generated content counts toward the bound.
