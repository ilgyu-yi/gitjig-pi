- The local hook tier's source fold decides its window by counting live `githook_source` frames on the shell's own call stack, instead of keeping a depth counter a sourced file could reach by name — closing an accidental corruption the counter carried. That counter was initialized at file scope with no re-entry guard, so a helper that re-sourced the prelude — an ordinary idiom that never names the counter — reset it inside an open window and drove it below its floor, and the next window then opened with no trap behind it. Measured against a tree carrying the counter: with one helper re-sourcing the prelude and a later helper exiting, the commit was refused with no stderr line and no record — the wedged hook with nothing printed, which is the refusal on machinery this tier never takes. Three other accidental shapes were measured not to move the counter, so the repair is that one direction plus the removal of a name a helper could assign to at all; reaching the window on purpose still forges an allow and stands as an enumerated residual.
