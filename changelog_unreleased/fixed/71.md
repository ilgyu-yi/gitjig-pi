- The local hook tier's source fold now decides its window from the shell's own call stack instead of a counter a sourced file can shift, closing both directions the counter carried: driven below its floor the next window opened with no trap behind it, so a helper's `exit` refused the commit with no message and no record; driven above it the window never closed and the trap outlived the sourcing function, firing at the adapter's exit where its `exit 0` created a commit whose refusal already stood in the record sink. The window is now recomputed from the live call stack at each decision instead of carried across the source, so no accident while a helper holds control can move it. What the fold is for is stated with it: an accidentally failing helper, not a deliberately hostile one — reaching the call stack on purpose still forges an allow, and stands as an enumerated residual beside the standing exposure that a sourced file can redefine any function in this shell.
