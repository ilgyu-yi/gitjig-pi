- The local hook tier's source fold decides its window by counting live `githook_source` frames on the shell's own call stack, instead of keeping a depth counter a sourced file could reach by name — so the tier carries no state across the point where a helper holds control. This is a simplification rather than a repair, and the record says so: measured against a reconstruction of the retired counter, no accidental helper failure moved it either, because every call site short-circuits on a non-zero return and an `exit` inside a helper terminates the shell in the trap, so no window ever follows a disturbed count. What changes is the price of moving the window on purpose — an `unset` and a refill of the call-stack array, rather than one assignment to a named global. Doing so still forges an allow, and stands as an enumerated residual beside the standing exposure that a sourced file can redefine any function in this shell, this one included. (#71)
