- The commit-msg hook no longer approves a commit whose subject is not the line it checked: it validates every line that could become the subject — the first non-blank line, the first non-blank non-comment line using git's own comment marker, and their trailing-trimmed forms — and approves only if all of them conform. A leading comment line and a subject that is grammatical only before git trims its trailing whitespace are both now refused. (#58)
