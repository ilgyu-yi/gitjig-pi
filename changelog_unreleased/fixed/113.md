- The local git-hook tier's protected-branch commit check no longer reads a branch name that is not the branch's own: it reads the full refname rather than git's shortest-unambiguous spelling, so a tag sharing the protected branch's name no longer disarms the check silently. A commit made while `HEAD` is on no branch now leaves one audit record naming the arm as not evaluated, instead of being indistinguishable from an ordinary allow. (#113)
