- Every recovery clause that hands a path to a named act — create the state directory, replace a non-directory ancestor, grant permission on it, make the sink a plain file — delimits that path for a shell paste instead of as a JSON string, so a path component carrying a command-substitution shape can no longer execute when the operator pastes the repair; the clauses that name a path only to say which filesystem is meant keep the JSON delimiter, and record why.
