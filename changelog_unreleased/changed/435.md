- SPEC §1.4 now defines the correction interval across a branch rewrite, so a pull request rebased between published repair reviews is no longer stranded with an underivable repair history: when a reviewed head is not an ancestor of the next, the interval is the branch-scoped delta — the change between the two heads restricted to paths either head changes relative to its own merge-base with the round's pinned base — which can overstate the author's correction but never understates it, and the history diagnosis runs as usual. This is the contract only; its runtime lands separately. (#435)
