- SPEC §1.4 now defines the correction interval across a branch rewrite: when a reviewed head is not an ancestor of the next, the interval is the branch-scoped delta — the change between the two heads restricted to paths either head changes relative to its own merge-base with the round's pinned base — which can overstate the author's correction but never understates it. This is the contract only: until its runtime lands, the installed gate still withholds the projection for such a pair. (#435)
